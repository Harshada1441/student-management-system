# 🎓 AI-Powered Student Management System

A modern Student Management System built using **Python, Flask, SQLite, Bootstrap, and Machine Learning**. The system helps teachers manage student records, attendance, marks, reports, and performance analytics through an interactive dashboard.

---

## 🚀 Features

### Authentication

* Login System
* Student Registration
* Role-Based Access (Teacher / Student)

### Teacher Dashboard

* View Total Students
* Average Marks Analytics
* Top Performer Tracking
* Student Rankings
* Attendance Analytics
* Dark Mode Support

### Student Management

* Add Student
* Edit Student
* Delete Student
* Search Student

### Academic Management

* Attendance Management
* Marks Management
* Subject-wise Marks
* Performance Tracking

### AI Features

* Machine Learning Based Student Performance Prediction
* Excellent Student Detection
* Good Student Detection
* Needs Improvement Detection

### Reports

* PDF Report Generation
* Student Ranking System
* Performance Analytics

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Harshada1441/ai-student-management-system.git
```

### Move into Project Folder

```bash
cd ai-student-management-system
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Virtual Environment

```bash
venv\Scripts\activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
python app.py
```
